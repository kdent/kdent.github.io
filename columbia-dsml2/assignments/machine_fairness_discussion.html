Discussion Topic: "Can a Machine Be Fair?"

Scenario: "Imagine a machine learning system is used to decide who gets interviewed for a job. It was trained on historical data from past decisions made by humans."

  • What could go wrong?
  • Would you trust this system? Why or why not?

Guiding Questions for Discussion

  • Group A: Imagine you are designing this system.
    • How will you build it?
    • What data will you use?
    • What advantages will the system give you?
    • Are there any potential downsides to building this system?
    • Any additional thoughts?
  • Group B: Think about the AI
    • What does it mean for a machine to be "fair"?
    • Should a machine always make the same decision a human would?
    • Can a machine be less biased than a human?
    • Can a machine be more biased than a human?
    • Any additional thoughts?
  • Group C: Think about the Data
    • Where do the patterns in machine learning come from?
    • If the data used to train the system has bias, what happens to the model?
    • Can you think of examples where real-world data might reflect unfairness?
    • Any additional thoughts?
  • Group D: Think about Ethics and Consequences
    • Should machines make important decisions about people’s lives (like in hiring, or more generally healthcare, education, law)?
    • Who should be responsible if an AI system makes an unfair or harmful decision?
    • If a system treats everyone equally, is that the same as being fair?
    • Any additional thoughts?
  • Group E: Think about Fairness Broadly
    • Can you design rules that a "fair" AI system should follow?
    • Would fairness always mean the same thing to different people?
    • Is it ever okay to use biased data, if the outcome seems accurate?
    • Any additional thoughts?
